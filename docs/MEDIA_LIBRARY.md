## Label schema

Each realization receives a stable working ID `AM-Rxxx` and a human-readable working title. These labels are intended to survive later migration into Avitus Materia OS.

Recommended fields:
- `realization_id` — stable internal label,
- `working_title` — human-readable name,
- `category` / `product_type`,
- `style_tags`,
- `materials_observed`,
- `material_status` — `OBSERVED`, `INFERRED`, or `TO_CONFIRM`,
- `date_source`,
- `source_folder`,
- `web_priority`,
- `recommended_use`,
- `legacy_brand_visible`,
- `privacy_review`,
- `missing_data`.

Do not infer exact wood species, provenance, finish, dimensions, price, client, or location from a photograph alone.

- **Collections:** SORA still needs a cleaner/lightweight realization; RUSTIC can use AM-R001/R002/R003; OLD OAK can use AM-R007 after material confirmation.
- **Custom / fit-to-space:** AM-R005.
- **Commercial / larger scale:** AM-R004.
- **Process:** workshop frames and R004 video.

# Data still needed from owners
For each realization, collect when available:
- confirmed product name,
- wood species,
- whether wood is new / old / reclaimed,
- provenance if publishable,
- finish (oil/oil-wax/stain etc.),
- dimensions,
- year/month of completion,
- client/project location at safe granularity,
- internal production time,
- selling price and actual cost **internal only**,
- permission to publish,
- collection mapping (`SORA`, `RUSTIC`, `OLD OAK`, custom),
- short project story / problem solved.

These fields will later let the media library become training/estimation context for pricing, configurator recommendations and similar-project retrieval in Avitus Materia OS rather than remaining only a photo gallery.
